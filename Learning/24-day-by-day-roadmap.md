# How to study

Follow the roadmap as a sequence, but do not treat the number of days as more important than understanding and pass tests. If a prerequisite is not understood, repeat it before moving forward.

# Labs

1) Complete fundamentals. 2) Complete embedded/STM32 bring-up. 3) Complete propulsion and power learning. 4) Complete sensor/estimation/control learning. 5) Complete communication/failsafe. 6) Test progressively. 7) Review flight readiness.

# Gandaberunda connection

The roadmap follows the V1 development strategy: Learn → requirements → architecture → hardware selection → individual hardware testing → sensor bring-up → communication → motor/ESC → flight controller → calibration → stabilization → basic flight → stable hover → safety validation → additional features.

# Must know
