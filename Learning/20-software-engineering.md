# How to study

Separate drivers, communication, estimation, control, safety and application logic. Keep interfaces clear. Make small changes, test them and record meaningful Git history.

# Labs

1) Create module boundaries. 2) Add a driver interface. 3) Add a state machine. 4) Add logging. 5) Write a small test. 6) Use a branch/commit workflow. 7) Review each other's changes.

# Gandaberunda connection

Communication, sensors, control, safety and hardware drivers should remain separate modules so the flight controller can be tested and upgraded without a complete rewrite.

# Must know

Modularity; interfaces; state machines; logging; Git workflow; review; traceable changes.

# Pass test

Both developers can explain the firmware architecture, make a small change safely and review the other developer's change.
