# How to study

Define expected behaviour before testing. Test the smallest unit first, then integrate progressively. A failed test is information: record the symptom, isolate the cause and verify the fix.

# Labs

1) Write a test case. 2) Test a peripheral. 3) Test communication. 4) Test sensors. 5) Test ESC signals with propellers removed. 6) Test failsafe. 7) Integrate progressively. 8) Review flight-test readiness.

# Gandaberunda connection

V1 development proceeds from individual hardware tests through sensor bring-up, communication, motor/ESC testing, flight-controller integration, calibration, stabilization, basic flight and hover.

# Must know

Expected vs actual; test evidence; progressive integration; safe fault injection; regression; flight-test gates.

# Pass test

Both developers can create a test case, define a safe test condition, collect evidence and justify whether a subsystem is ready for the next stage.
